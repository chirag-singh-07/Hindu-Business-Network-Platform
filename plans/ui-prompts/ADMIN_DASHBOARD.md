# UI Prompt — Admin Dashboard
Design a secure, dense but approachable Hindu Business Network operations console in existing `admin-panel/`. Echo the logo identity with a small HBN mark, restrained saffron accent, warm neutral backgrounds, charcoal text and vermilion for destructive/urgent states. Keep ceremonial logo imagery out of data-heavy workflows. Inter with Noto Sans Devanagari. Prioritize clarity, evidence and auditability over marketing visuals.

Screens: MFA sign-in/session timeout; overview of only real operational metrics; business verification queue/detail; member status/support with masked PII; report/moderation case; ad review with creative, destination, policy and reasoned approve/reject; plan/entitlement editor with version diff; subscription/payment reconciliation; reputation rules/badge criteria; privacy export/deletion requests; notification templates; role/access management; searchable audit log. Every sensitive action shows scope, reason, consequence, confirmation and recorded actor. Message content is unavailable by default; exceptional reviewed content appears only within authorized case workflow and audit context.

Layout: persistent sidebar, top identity/environment banner, searchable data tables, filter chips, pagination, detail side panel, explicit empty/loading/error states. Reusable status badge, permission-aware action, masked field, audit timeline, reason dialog, diff viewer, case evidence panel. Support keyboard-first navigation, accessible tables, session expiry warning, responsive tablet layout. Never show fake data as live; clearly label synthetic staging data. Prevent actions when user lacks permission and explain access denial without leaking protected records.
