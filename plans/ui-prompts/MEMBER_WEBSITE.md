# UI Prompt — Member Website
Create responsive Next.js member website for Hindu Business Network using actual logo identity: saffron/marigold, vermilion Devanagari/English lettering, orange flags, trident/damru/Om, handshake, blue accent and community figures. Translate ornate badge into a restrained professional interface: warm ivory/white cards, charcoal typography, saffron primary CTA, vermilion sparingly, blue secondary links/trust. Inter + Noto Sans Devanagari; use full logo in brand areas and compact HBN mark in persistent navigation. Heritage should feel welcoming and credible, not ornamental on every control.

Specify pages and flows: dashboard/feed with create post and filters; directory with search and facets; profile/business detail with explicit public/private contact states; connection requests and mutuals; membership comparison/checkout/history with cancellation; chat list/thread; reviews/rankings/badges; ad draft/payment/approval/performance; notifications; profile/privacy/security/consent/export/delete. Include public profile variant with SEO-safe fields.

Desktop: left navigation, central feed/content, contextual right rail only when useful. Mobile web collapses to compact navigation and stacked cards, no horizontal overflow. Components: header/search, breadcrumbs, cards, post composer/feed, profile hero, filter controls, entitlement notice, tables/status timeline, modal/drawer, pagination, skeleton/empty/error/retry. Define keyboard paths, focus, form validation, contrast and screen-reader semantics. Public/private API fields must be distinct in rendered and cached output. Design free upgrade gates as contextual and transparent; all controls must map to real actions and show server errors/loading states.
